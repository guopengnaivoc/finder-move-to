# 移动到… — Finder 右键「移动到」快速操作

给 macOS 访达(Finder)的右键菜单加一个 **「移动到…」** 快速操作:选中文件/文件夹 → 右键 → **移动到…** → 弹框选目标文件夹 → **直接移动过去**(真移动,不是复制副本)。

- 🍎 **纯 macOS 原生**:只用系统自带能力(AppleScript + Automator 服务),**零第三方软件**。
- 🔝 **右键顶层显示**:出现在右键的「快速操作」区,文件和文件夹都在。
- 🔁 **同名冲突可选**:目标已有同名项时弹框让你选 **替换 / 两者都保留 / 跳过**。
- ⚡ **开机即用**:安装后是一个常驻的菜单项,重启、关机再开都在,不需要打开任何程序。

## 环境要求

- macOS(在 macOS 26 / Apple Silicon 上开发验证;较老版本原理相同)。
- 系统自带的 `python3`、`osascript`、`Automator` —— 无需额外安装。

## 安装

```bash
./install.sh
```

脚本会用 `build.py` 生成快速操作 bundle,拷贝到 `~/Library/Services/`,并刷新服务缓存。

安装后如果右键里没立刻出现,重启一下访达即可:

```bash
killall Finder
```

## 使用

1. 在访达里选中一个或多个文件/文件夹。
2. 右键 → 在「快速操作」区点 **移动到…**。
3. 在弹出的文件夹选择框里选目标文件夹。
4. 选中项被**移动**过去(源位置不再有)。

首次使用时,系统可能弹出「"移动到…" 想要控制访达」的授权框,点 **允许** 即可(只需一次)。在选择框点 **取消** 不会做任何操作。

### 同名冲突处理

如果目标文件夹里已存在同名文件/文件夹,会弹框让你选择:

| 选项 | 行为 |
|------|------|
| **替换** | 用移动过来的覆盖旧的;旧的移入**废纸篓**(可恢复) |
| **两者都保留** | 自动把移过来的改名(如 `报告.pdf` → `报告 2.pdf`),两个都留着 |
| **跳过** | 这一项不动,继续处理其余项 |

多选时逐项询问;个别项失败(如无权限)会在最后汇总提示,不影响其余项。

## 卸载

```bash
./uninstall.sh
```

## 工作原理

- `src/move_to.applescript` —— 核心逻辑:弹出文件夹选择框、检测同名冲突、执行移动。其中 `moveOne` / `hasConflict` / `uniqueName` 等纯逻辑处理器可被自动化测试。
- `build.py` —— 用 Python `plistlib` 把上面这段 AppleScript 注入生成一个 Automator 服务工作流 bundle(`移动到….workflow`)。让它以「快速操作」形式出现在右键顶层的关键,是工作流元数据里的 `presentationMode = 15` 与 Info.plist 的图标键。
- `install.sh` / `uninstall.sh` —— 安装/卸载到 `~/Library/Services/` 并刷新服务缓存。

## 开发

```bash
# 生成 bundle
python3 build.py

# 运行测试(会驱动 Finder,首次需授权自动化)
./tests/test_moveitems.sh   # 移动语义 + 同名冲突三种处理
./tests/test_build.sh       # bundle 结构、plist 合法性、注入内容一致
```

设计与实现文档见 [`docs/superpowers/`](docs/superpowers/)。

## 手动验收

1. 新建两个文件夹 `A`、`B`,`A` 里放一个测试文件。
2. 右键 `A` 里的文件 → 快速操作 → **移动到…** → 选 `B` → 确认文件从 `A` 移到了 `B`。
3. 在 `A`、`B` 各放一个同名文件 → 移动 → 确认弹出冲突框,三个按钮行为符合预期。
4. 选择框点「取消」→ 确认文件原封不动。
